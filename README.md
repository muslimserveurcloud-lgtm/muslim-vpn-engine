# MUSLIM VPN ENGINE

Moteur réseau autonome expérimental pour Termux / Android ARMv7.

Objectifs :
- Tests TCP et UDP
- Client proxy HTTP CONNECT
- Relais SOCKS5
- Intégration progressive de moteurs VPN multi-protocoles
- Diagnostic DNS et connectivité
- Journaux et configurations séparées

Les tests de transport ne constituent pas à eux seuls un VPN
système complet. Android non rooté impose des restrictions TUN.
